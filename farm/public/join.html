DVForge

Set up a worker

No NAS mount. One command starts local DVForge (and on the Mac, the farm API) and joins this farm over HTTPS.


  
You should see starting DVForge (or already running), then queue=https://api.nas86.eu and claiming windows-* (or macos / linux). On the Mac, --with-queue also starts the farm API if :8766 is down. The optional webhook receives an alert only after the worker goes offline for more than 45 seconds, then another when it recovers; no startup message is sent. Ctrl+C stops the worker and the DVForge it started; the farm API stays up. If the log shows queue=%DVFORGE_QUEUE% you are in PowerShell — use the flags above, not set / %VAR%.
